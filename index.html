    Notes

    Where the numbers on this page come from.

    Source of truth

    The KiCad file attiny412-pulsenode.kicad_pcb is parsed by tools/build_assets.py. Nets, pads, tracks and unrouted counts are computed from that parse, not typed in.

    3D model

    The board and part bodies are simple extruded envelopes written to assets/board.stl, assets/parts.stl and the STEP assembly. They show size and placement, not manufacturer part models.

    Rebuild

    With build123d installed, run python tools/build_assets.py to regenerate the JSON, STL, STEP, Gerbers and hashes.

    Open it locally

    This page loads JSON and ES modules, so serve the folder (for example python3 -m http.server) instead of opening the file directly.
